# Multimodal investigation

SEA v0.4 adds two tools to the local stdio server.

| Tool | Arguments | Output |
| --- | --- | --- |
| sense_video | path, start_s, duration_s | Sampled visual features, change regions and event intervals; 0.25–120 s |
| investigate_media | path, start_s, duration_s, tolerance_s | Audio/visual event evidence, nearest temporal matches and up to eight frame follow-ups; 0.25–30 s |

Use absolute paths in an authorized media root. A video-only or audio-only recording is supported by investigate_media; an absent modality is explicit. If a present stream cannot be decoded, the call fails rather than claiming that the stream is absent.

## Workflow

1. Inspect media metadata and select a bounded window.
2. Call investigate_media to collect threshold-based observations and report-local A/V evidence IDs.
3. For each audio level transition, the report finds the nearest point visual event if it lies within tolerance (default 0.5 s, range 0–2 s). Several audio events may reference the same visual event.
4. Follow recommended timestamps using view_frame; compare them to a nearby earlier frame and the numeric evidence.
5. Explain what the observations support and what remains unknown. Do not infer causation from temporal proximity.

For longer files, use sequential bounded windows; boundary transitions can be missed, so overlap windows when relevant. There is no automatic whole-file indexing yet.

## Visual measurements

The first video stream is sampled in padded 160 × 90 grayscale at 4 fps. Each adjacent sample pair yields mean absolute pixel difference (0–1), fraction of pixels changing by at least 10% of full scale, and total-variation distance between normalized 16-bin brightness histograms.

- large_global_change: mean difference >= 0.12 AND histogram distance >= 0.35.
- pixel_activity: at least 5% changed pixels, if the global rule did not match.
- low_change_interval: consecutive sample differences <= 0.005 spanning at least 1 s.
- change_region: normalized [left, top, right, bottom] bounding box of all threshold-crossing pixels, present at >= 0.5% changed pixels. Coordinates refer to the padded sample and do not represent a tracked object.

These are heuristic visual observations, not confirmed cuts, motion tracking or freeze detection. Color-only transitions and small/fast changes may be missed. A/V offsets are approximate decoded times rather than exact presentation timestamps. The audio detector uses the rules in [acoustics.md](acoustics.md).

## Verification

The synthetic fixture generated by examples/make_demo.py contains a 440 Hz tone and visual changes around 2 and 4 seconds. Tests expect nearby A/V event pairs, and separately check static frames, local change regions, audio-only behavior, and duration limits. These are reproducible test cases, not a real-world accuracy benchmark. See [CI](https://github.com/PCTestAdmin/SEA/actions/workflows/test.yml).

Tool results and requested images are sent to the MCP host/model. See [privacy and installation](installation.md).
